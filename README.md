# Planejamento Pro v1

Primeira versão de um produto de planejamento pessoal + profissional.

## Funcionalidades
- Dashboard comercial em tema escuro
- Tarefas com área, prioridade, data, horário e projeto
- Projetos
- Metas
- Hábitos
- Notas
- Calendário com tarefas
- Agenda de próximas tarefas
- Gráficos de atingimento por área
- Gráfico de evolução semanal
- Dados salvos no navegador com localStorage
- Layout responsivo

## Publicar no GitHub Pages
Substitua no seu repositório:
- index.html
- style.css
- script.js

O GitHub Pages fará o novo deploy automaticamente.
